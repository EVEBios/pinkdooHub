# TabBar icons

The four navigation symbols are derived from Heroicons v2.2.0:

- `building-storefront` for 商城
- `calendar-days` for 预约
- `document-text` for 订单
- `user` for 会员中心

The source SVGs are published by Tailwind Labs under the MIT License. They are rasterized locally at 81 × 81 px in the product's ink, white, and berry colors so every Taro target can consume stable local assets without a runtime icon dependency. See `HEROICONS_LICENSE.txt` for the upstream license.
