# Admin visual assets

## `workbench-header-texture.jpg`

- Purpose: decorative full-bleed background for the ADMIN+ shop workbench header.
- Source: generated with the built-in OpenAI image generation tool on 2026-09-09, using the user-provided Option 2 header screenshot as a style reference.
- Production derivative: resized from the generated `2170 × 725` PNG to a `1500 × 501` JPEG at quality 86 so the multi-platform bundle keeps sufficient 3× mobile density without carrying the 1.7 MiB source file.
- Constraints: no text, logo, icon, person, product or device chrome is embedded in the asset. All workbench copy remains accessible UI text.
- Palette: deep plum and berry tones designed to keep the left text area dark and place the more visible layered bands toward the right.
