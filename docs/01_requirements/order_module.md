# 订单模块（Order Module）

---

## 1. 模块目标

订单模块负责管理用户购买商品后的整个交易流程，包括订单创建、订单查询、订单状态管理以及订单完成。

---

## 2. 用户角色

### 普通用户

| 功能 | 说明 |
|------|------|
| 创建订单 | 选择商品后生成订单 |
| 查看订单列表 | 查看自己的订单记录 |
| 查看订单详情 | 查看单笔订单完整信息 |
| 取消订单 | 仅可取消"待支付"状态的订单 |

### 管理员

| 功能 | 说明 |
|------|------|
| 查看所有订单 | 分页浏览全部订单 |
| 查看订单详情 | 查看任意订单完整信息 |
| 修改订单状态 | 特殊情况下手动干预 |
| 统计订单数据 | 订单数据汇总与分析 |

---

## 3. 下单流程

```
用户浏览商品
    ↓
选择商品（类型、数量）
    ↓
创建订单
    ↓
生成订单编号
    ↓
等待付款（订单状态：待支付）
    ↓
付款成功（订单状态：已支付）
    ↓
订单完成（订单状态：已完成）
```

| 步骤 | 操作 | 角色 |
|------|------|------|
| 1. 浏览商品 | 查看商品列表和详情 | 普通用户 |
| 2. 选择商品 | 选择商品类型和数量 | 普通用户 |
| 3. 创建订单 | 提交订单生成请求 | 普通用户 |
| 4. 生成编号 | 系统自动生成唯一订单号 | 系统 |
| 5. 等待付款 | 订单进入"待支付"状态 | - |
| 6. 付款成功 | 订单进入"已支付"状态 | - |
| 7. 订单完成 | 服务完成，订单进入"已完成" | 管理员 |

---

## 4. 订单信息

每个订单包含：

| 字段 | 说明 |
|------|------|
| 订单编号 | 系统生成的唯一编号 |
| 下单用户 | 关联的用户 ID |
| 商品信息 | 商品名称快照 + 商品价格快照 |
| 商品数量 | 每种商品的下单数量 |
| 订单金额 | 订单总金额 |
| 创建时间 | 下单时间 |
| 当前状态 | 订单状态 |
| 备注 | 用户填写的附加信息 |

> **快照设计**：订单保存时记录商品名称和价格的快照，保证历史订单不受商品后续修改影响。

---

## 5. 订单状态

### 状态定义

| 状态 | 值 | 说明 |
|------|-----|------|
| 待支付 | 0 | 订单已创建，等待付款 |
| 已支付 | 1 | 付款成功，订单处理中 |
| 已取消 | 2 | 用户取消或超时自动取消 |
| 已完成 | 3 | 订单流程结束 |

### 状态流转

```
待支付 ──→ 已支付 ──→ 已完成
   │
   └──→ 已取消
```

| 流转 | 触发方 | 条件 |
|------|--------|------|
| 待支付 → 已支付 | 系统 | 付款成功 |
| 待支付 → 已取消 | 用户 | 主动取消 |
| 待支付 → 已取消 | 系统 | 超时自动取消 |
| 已支付 → 已完成 | 管理员 | 服务完成确认 |

## 6. 查询功能

### 普通用户

| 查询方式 | 说明 |
|----------|------|
| 我的订单 | 查看自己的所有订单 |
| 按状态筛选 | 筛选特定状态的订单 |

### 管理员

| 查询方式 | 说明 |
|----------|------|
| 全部订单 | 查看所有用户订单 |
| 按订单编号 | 精确查找某笔订单 |
| 按订单状态 | 筛选特定状态的订单 |
| 按用户 | 查看某用户的所有订单 |
| 按时间范围 | 按日期区间筛选 |
