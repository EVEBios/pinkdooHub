# 用户模块（User Module）

---

## 1. 模块目标

负责平台用户注册、登录、身份认证以及个人资料管理。

---

## 2. 用户角色

| 角色 | 说明 |
|------|------|
| 游客 | 未登录，可浏览公开内容 |
| 普通用户 | 已登录，可操作个人数据 |
| 管理员 | 已登录，可管理所有用户 |

---

## 3. 功能矩阵

### 游客

| 功能 | 说明 |
|------|------|
| 注册 | 创建账号 |
| 登录 | 用户名 + 密码 |
| 浏览商品 | 查看商品列表和详情 |

### 普通用户

| 功能 | 说明 |
|------|------|
| 查看个人信息 | 获取个人资料 |
| 修改个人信息 | 修改昵称、手机号 |
| 修改密码 | 验证旧密码后更新 |
| 头像 URL | 可随个人资料保存；头像文件上传尚未实现 |
| 查看订单 | 查看自己的订单记录 |

### 管理员

| 功能 | 说明 |
|------|------|
| 查看用户列表 | 分页浏览所有用户 |
| 禁用用户 | 将用户状态设为禁用 |

当前管理能力只包含严格分页列表与禁用。用户详情、启用和头像文件上传属于后续范围，不得依据旧规划提前实现前端入口。

---

## 4. 登录方式

### v0.1

| 方式 | 说明 |
|------|------|
| 用户名 + 密码 | 主要登录方式 |

### 后续计划

| 方式 | 计划版本 |
|------|----------|
| 手机验证码 | v0.2 |
| 微信登录 | v1.0 |
| OAuth 登录 | v1.0 |

---

## 5. 权限模型

| 角色 | 权限范围 |
|------|----------|
| 游客 | 浏览商品、注册、登录 |
| 普通用户 | 游客权限 + 个人资料管理 + 创建/查看自己的订单 |
| 管理员 | 普通用户权限 + 管理所有用户、管理所有商品、管理所有订单 |

---

## 6. 用户数据

| 字段 | 说明 |
|------|------|
| 登录账号 | 唯一标识，用于登录 |
| 密码 | 加密存储 |
| 昵称 | 显示名称 |
| 手机号 | 可选，用于联系 |
| 头像 | 可选，个人头像图片 |
| 角色 | 普通用户 / 管理员 |
| 状态 | 正常 / 禁用 |

---
