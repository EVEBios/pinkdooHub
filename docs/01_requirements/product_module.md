# 商品模块（Product Module）

---

## 1. 模块目标

商品模块负责管理拼豆店提供的服务与商品，包括拼豆体验和拼豆套装的管理，并为订单模块提供商品信息。

该模块面向两类用户：

- 普通用户：浏览商品、查看详情
- 管理员：管理商品信息

---

## 2. 商品类型

系统中的商品分为两类：

### 拼豆体验

用户购买的是指定时长的拼豆体验。

| 示例 | 时长 | 人数 |
|------|------|------|
| 工作日单人 | 1 小时 | 1 人 |
| 工作日双人 | 2 小时 | 2 人 |
| 周末单人 | 2 小时 | 1 人 |
| 周末双人 | 3 小时 | 2 人 |

体验商品包含：

| 属性 | 说明 |
|------|------|
| 体验时长 | 以小时为单位 |
| 适用人数 | 单人 / 双人 |
| 日期类型 | 工作日 / 周末 |
| 售价 | 不同组合不同价格 |

### 拼豆套装

用户可以购买已经搭配好的拼豆套装。

| 示例 |
|------|
| 新手体验套装 |
| 动漫主题套装 |
| 节日限定套装 |

每个套装内容固定，不支持用户自由组合。

套装包含：

| 属性 | 说明 |
|------|------|
| 套装名称 | 展示名称 |
| 套装介绍 | 详细描述 |
| 套装图片 | 多张展示图 |
| 售价 | 统一售价 |
| 库存 | 可售数量 |

---

## 3. 用户角色

### 游客

| 权限 |  |
|------|------|
| 浏览商品列表 | ✅ |
| 查看商品详情 | ✅ |
| 创建订单 | ❌ |

### 普通用户

| 权限 |
|------|
| 浏览商品列表 |
| 搜索商品 |
| 查看商品详情 |
| 创建订单（订单模块） |

### 管理员

| 权限 | 说明 |
|------|------|
| 创建商品 | 新增体验或套装 |
| 修改商品信息 | 更新名称、描述、价格等 |
| 删除商品 | 逻辑删除，不可逆 |
| 上架商品 | 将草稿或下架商品恢复上架 |
| 下架商品 | 将上架商品下架 |
| 管理库存 | 仅拼豆套装需要 |

---

## 4. 商品信息

每个商品包含以下信息：

### 基础信息

| 字段 | 说明 |
|------|------|
| 商品名称 | 展示名称 |
| 商品类型 | 体验 / 套装 |
| 商品描述 | 详细说明文本 |
| 商品图片 | 主图 + 详情图 |

### 价格信息

| 字段 | 类型 |
|------|------|
| 商品售价 | Decimal(10,2)，单位：元 |

### 库存信息

| 商品类型 | 库存策略 |
|----------|----------|
| 拼豆体验 | 无需库存，不限制数量 |
| 拼豆套装 | 记录库存，售卖时扣减 |

### 状态信息

| 状态 | 说明 |
|------|------|
| draft（草稿） | 编辑中，用户不可见 |
| online（上架） | 已发布，用户可见可购买 |
| offline（下架） | 已下架，用户不可见 |

---

## 5. 商品生命周期

```
草稿 ──→ 上架 ──→ 下架
  ↑                 │
  └───────←─────────┘
        (重新上架)
```

| 流转 | 触发角色 | 说明 |
|------|----------|------|
| 草稿 → 上架 | 管理员 | 发布商品 |
| 上架 → 下架 | 管理员 | 下架商品 |
| 下架 → 上架 | 管理员 | 重新上架 |

---

## 6. 商品图片

一个商品可以拥有多张图片：

| 类型 | 说明 | 数量 |
|------|------|------|
| 主图 | 列表展示用，封面图 | 1 张 |
| 详情图 | 详情页展示用 | 多张 |
| 展示图 | 附加展示 | 多张 |
