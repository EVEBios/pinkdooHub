# 付款后会员桌台入口消失修复 · 2026-09-14

## 问题与处理

原会员入口依赖 table_total > 0；该数量仅包含有效待付款与独立未读桌台结果。人工／余额付款后，待付款消除，付款结果归入订单，正常使用中的桌台没有独立红圈，因此入口和原提醒列表均不可见。

- 会员专用外观固定展示“我的桌台”，0 只隐藏角标；首次汇总未返回、汇总失败、钱包失败时仍保留入口。首页原有提醒显示规则不变。
- 顾客“全部桌台”读取新的本人记录接口；待付款／新结果与管理员队列继续读取原提醒集合。接口从认证推导 user_id，不接收跨用户筛选。
- 新列表包含使用中及已读历史记录，按 created_at、id 降序稳定分页，复用安全响应投影与精确 session_no 详情路径。页面读取不标已读，正常使用中的记录不增加提醒计数。
- 状态按服务端绝对时间派生，待付款截止等号仍有效，桌台释放等号视为结束，不要求后台先把持久状态改为 closed。
