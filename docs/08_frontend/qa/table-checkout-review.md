# 统一选桌结算检查记录

日期：2026-09-14。范围：扫码商品目录、商品详情、购物车、订单确认、顾客订单详情、管理员订单收款及关联提醒。

## 已实现流程

1. 扫码成功后保存本次购物桌台，离开扫码页进入商品详情/购物车仍可见；更换桌台需确认。
2. 商城确认页可扫码或输入桌号，服务端解析后让顾客核对。不选桌保持普通下单；纯材料包不能开台。
3. 新开台订单创建、明细、占台、库存与审计原子提交；重复请求返回原订单。无需返回扫码页补选订单。
4. 订单详情可为未绑定/已结束的待付款体验订单选桌，已有有效会话展示桌号与付款倒计时。
5. 用户和管理员付款携带确认的精确会话；普通入口的服务端同样阻止已超时/已结束会话退化为普通付款。
6. 未知提交按账号保存原请求，重新进入时核对原单。恢复时保留现有购物车并提示核对，避免误删后来加入的商品。
7. 结果提醒对已确认事件去重，旧快照不重复标记已读；保存失败保留提示，显式重试。
