# 预约待办精修与过期展示：Product Design 检查

日期：2026-09-14。范围为既有项目页面修订，无新原型、路由、图片资产、依赖或数据库迁移。

## 问题与修正

1. 原待办页与既有管理页面的视觉语言不一致：纯文字标题、分散的大按钮、缺乏空状态层次。修订后复用真实莓红纹理页头、圆角白面板、胶囊筛选、预约卡片及既有字体/颜色变量。保留整行触控。
2. 原“管理预约”按持久化 pending 展示“待确认”，没有识别已经错过开始时间的记录。新管理筛选区分尚可确认与已过期，服务端按 UTC 时间在分页前筛选。顾客与管理列表/详情统一显示“已过期未处理”，过期管理详情收起确认/拒绝操作。
3. 无待审核、只有过期记录时，旧首页入口进入空列表。现在初次进入优先第一个非空集合；手动切换后保留选择，待审核空状态提供“查看 N 条过期预约”。

## 设计来源与同输入比较

用户本轮提供的待办截图为问题来源；项目已有管理预约/工作台、`styles/patterns`、`admin/styles/surface`、Ribbon Ledger 纹理与 tokens 为视觉来源。原图是裁切画面，按 390px 宽度缩放参与内容比较；新页面使用浏览器实际 390px CSS 视口。未将裁切范围差异当作实现偏差。

[同输入比较图](attention-refinement/comparison.png) 将原待办页、修订后的同一空状态和当前既有管理预约样式并排显示。已核对页头、筛选组、文字层级、圆角、边线、卡片、触控入口和空状态；无需新增装饰图或图标。过期与待确认通过文字和独立筛选表达，不只靠颜色。
