# 开台与新增提醒页面按钮间距检查

2026-09-14，按用户提供的微信截图检查“确认开台并进入付款／继续挑选商品”和“使用会员余额付款／刷新状态”粘连问题。限定局部间距，保留当前配色、布局、文字和业务操作。

## 原因与修改

`table-action` 已有 18px 顶部间距，但同一按钮附加的 `table-action--secondary` 在后面调用公共按钮 mixin，内部 `margin: 0` 清除了该间距。现将次要按钮的间距放在 mixin 之后，编译成 18rpx。该修复同时覆盖不可再次开台、订单核对失败和计时校准等复用按钮的状态。

管理员桌台列表主收款按钮、会话详情收款按钮也有后置主题样式覆盖间距，分别恢复 12rpx 和 10rpx；会话详情原有父容器 gap 仍保留。新订单／桌台提醒页与历史桌台页的未登录按钮使用既有 `attention-page__retry`，与提示文字保持 12rpx 留白。
