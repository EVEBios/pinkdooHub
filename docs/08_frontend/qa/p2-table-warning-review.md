# P2.3 桌台到时预警检查记录

日期：2026-09-15。范围：管理员首页、桌台列表与会话详情；用户确认提前 **10 分钟**。此记录证明仓库实现、下列自动化/界面检查及末节列明的用户验收，不代表持久环境迁移或发布验收；手机自然缓冲/释放未在本轮等待验证。

## 实现与规则

- 首页“桌台工作台”红圈合并有效待付款桌与到时桌，两类从同一列表快照按桌去重，进入完整桌台工作台。
- 逐组计算即将到时／缓冲；短时长组不被最长组覆盖。直接开台和暂停新开台的活动桌同样提醒。列表提供完整“全部桌台／需关注”按钮，详情突出对应组。
- 阅读不消除预警；单组缓冲结束不继续提醒该组；整桌时间已到但服务端仍活动时保留核实提示，服务端确认释放后消除。
- 每个可见页面单请求轮询，后台暂停秒级刷新与轮询，回前台立即校准；身份变更不继承旧数据。错误保留已有快照并说明时效；首次读取失败明确提示重试。
- API 仅增加各组轻量摘要，复用既有预加载，不修改数据库结构、资金流程、自动释放规则或顾客端提醒，不接入微信推送。

权威规则见 [桌台需求](../../01_requirements/table_session_module.md)；响应与先后兼容顺序见 [桌台 API](../../03_api/table_session_api.md)。
